Quick Start

Up and running in about five minutes.

1. Download

Go to the Releases page and open the newest release. Under Assets, download:

  • Windows: PIN-Browser Setup <version>.exe
  • Mac: the .dmg file (arm64 for Apple Silicon Macs, x64 for Intel Macs, when both are offered)

2. Install on Windows

  1. Double-click the .exe you downloaded.
  2. Windows may show a blue box saying "Windows protected your PC" (Microsoft Defender SmartScreen). That's because the beta isn't code-signed yet. Click More info, then Run anyway.
  3. Accept the license, choose where to install (or keep the suggested folder), and finish. You get a desktop shortcut and a Start menu entry called PIN-Browser.

3. Install on a Mac

  1. Open the .dmg and drag PIN-Browser into your Applications folder.
  2. The first time, don't double-click it. Instead right-click (or Control-click) PIN-Browser in Applications and choose Open, then click Open in the box that appears. This gets past Gatekeeper's "can't be opened because it is from an unidentified developer" warning.
  3. On newer versions of macOS, if there's no Open button: try to open it once, then go to System Settings > Privacy & Security, scroll down, and click Open Anyway.
  4. After that, open it the usual way.

4. First run: choose your day log folder

The first time PIN-Browser starts, it asks "Where should PIN-Browser save your day log?" Screenshots, page text, recordings and downloads all go in this folder, one folder per day. Nothing is saved until you choose.

  • Use suggested folder uses the folder it shows (on Windows that's C:\Users\<you>\AppData\Roaming\PIN-Browser\daylog).
  • Choose folder... lets you pick any folder. A drive with plenty of space is a good idea, for example D:\pin_browser_daylog on Windows. The day log grows a little every day.
  • Leave "Save the debug log in the same folder" ticked. It's a small text file that helps if you report a bug.

You can change the folder later in Options > Recording and Day log.

5. Try it

  1. Type an address in the address bar and press Enter. Browse as usual.
  2. The Day log: ON button shows the day log is saving.
  3. After a few minutes, press Ctrl+Shift+D (Cmd+Shift+D on a Mac) to open Dial back and scrub through what you saw. Click the address under the picture to open that page again.
  4. Press Ctrl+B to see all your tabs, or Ctrl+Shift+G for the tab grid.
  5. Open Options with the gear button or Ctrl+,.
